# Airbnb Prices for London and Istanbul

This project aims at analyzing and comapring Airbnb prices for the two most visited European cities[^readme-1], which are London (The United Kingdom) and Istanbul (Türkiye) with 22.7 and 19.7 million visitors respectively.

[^readme-1]: Wikipedia - 2025 data <https://en.wikipedia.org/wiki/List_of_cities_by_international_visitors>
